The poster's title is set in big block letters, much like the output of the
[`banner`](https://en.wikipedia.org/wiki/Banner_(Unix)) command. `banner` takes a
string and prints it in oversized letters built from ordinary characters. On a
shared line printer that was practical: each job started with a separator page
carrying the owner's name in letters big enough to spot in a pile of fanfold
paper.

Two versions survive. System V's `banner` prints horizontally at a fixed size.
The BSD one, by Mary Ann Horton at Berkeley, prints sideways down the page, so
the message can run as long as the paper does. FIGlet does the same job today
with many more fonts.
